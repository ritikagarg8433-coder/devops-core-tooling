I would like to share a brief summary of the improvements achieved by migrating from manual FTP-based deployments to a Git-based GitHub Actions CI/CD workflow.

**Challenges with Manual FTP Deployments**

Previously, our deployment process relied on manually transferring application files to servers using FTP. This approach increased the possibility of human errors, incorrect file uploads, inconsistent deployments, and limited visibility into deployment activities.

**Implemented Solution**

We introduced a Git-based deployment workflow using GitHub and GitHub Actions. This automated approach provides:

- Version control and tracking of code changes.
- Automated code quality checks using Flake8.
- Automated testing using Pytest.
- Consistent validation through GitHub Actions workflows.
- Improved visibility into successful and failed workflow executions.

**Business Impact**

The migration resulted in an 80% reduction in deployment errors.

This improvement has helped reduce manual intervention, improve deployment consistency, strengthen code quality, and increase the reliability of our software delivery process.

**Conclusion**

Moving from manual FTP deployments to GitHub Actions CI/CD has made our deployment process more reliable, efficient, and manageable. It also establishes a foundation for further automation and continuous improvement.
